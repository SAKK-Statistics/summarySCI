# Save a flextable to a Word document

What
[`summaryTable()`](https://sakk-statistics.github.io/summarySCI/reference/summaryTable.md),
[`summaryByVisit()`](https://sakk-statistics.github.io/summarySCI/reference/summaryByVisit.md)
and the wrappers do with `word_output = TRUE`.

## Usage

``` r
save_word(ft, file_path)
```

## Arguments

- ft:

  A flextable.

- file_path:

  Path of the `.docx` file.

## Value

`file_path`, invisibly.
